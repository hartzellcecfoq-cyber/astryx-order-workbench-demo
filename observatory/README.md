# NIGHTWATCH 深空观测台

这是一个纯前端观测控制台。支持切换趋势时间范围、按测站和核验状态筛选事件、搜索目标、查看详情、核验事件并导出 CSV。核验状态存储在当前浏览器中，观测量、测站分布和事件内容均为模拟数据。

通过静态 HTTP 服务访问本目录即可运行，无需构建。入口是 `index.html`。

首页土星影像来自 [NASA Photojournal PIA17218, A Farewell to Saturn](https://science.nasa.gov/photojournal/a-farewell-to-saturn/)。影像署名 NASA/JPL-Caltech/Space Science Institute。
